# 绘本 Prompt 手册写法

把一个陌生行业变成一座**可以漫游的城市**：行业里流动的核心资源变成城市里看得见的东西（例如金融里“钱 = 金色的水”），各类机构变成城市设施，各种岗位变成城里干活的小人。主角 Sylvan 跟着向导机器人比特一路走、一路追问，读者跟着他看懂行业。

产出物是一份可以直接拿去逐页出图的手册。完整范例见仓库里的 `examples/computer/picture-book-prompts.md`（《比特城漫游记》，45 页）和 `examples/finance/picture-book-prompts.md`（《金流城漫游记》，41 页）。

## 输入

- **行业名称**（必填），例如“金融”“半导体”“医药”。
- **配套的行业速通手册**（应先写好，见 `handbook-guide.md`）。绘本的章节、岗位页和学习之路都跟它对齐。
- **前作定妆图**（可选）。系列里主角始终是同一个 Sylvan 和比特，复用前作定妆图即可。

## 工作流

### 1. 找到城市的核心比喻

先回答一个问题：**这个行业里流动的是什么？** 把它画成一种会发光、会流动的东西，整座城市按它的流向分层。

- 计算机：按价值链分层的城市。岩床是数学，地下发电厂是芯片与算力，街道和气动信管是网络，市政厅管家是操作系统，彩色楼房是软件产品，档案馆与水厂是数据，中央玻璃高塔是 AI，城墙是安全，天上可租用的“云工厂”是云计算。
- 金融：钱 = 金色的水。屋顶集水槽（储蓄）→ 水库（资金池）→ 水闸塔（央行）→ 泵站（银行）→ 运河（支付清算）→ 集市（交易所）→ 磨坊（企业），堤坝是监管，大雨伞是保险，齿轮钟塔是金融科技。
- 把比喻做成一张“城市设定表”：层 / 画面元素 / 代表什么。全书每一页都只能用这张表里的地标，保证读者翻到哪一页都认得出自己在城里的哪里。
- 给城市起名“X流城 / X城”，书名《X城漫游记》。

### 2. 搭全书骨架（约 40–45 页）

按这个结构排页，章节跟速通手册一一对应，页数可以按行业增减：

| 部分 | 内容 | 对应手册 | 计算机范例 | 金融范例 |
| --- | --- | --- | --- | --- |
| 序章 | 封面；这个行业到底在做什么；每条第一性原理一页；城市全景剖面 | 导读 | P1–P7 | P1–P7 |
| 正文各章 | 每章一层课程或一个板块，每页一门课或一个概念 | 课程阶梯 L0–L4 | 地基：数学 → 语言：编程 → 机器的内部 → 盖楼 → AI | 语言 → 货币银行 → 资本集市 → 管钱的人 → 风险与规则 → 金融科技 |
| 城里的人 | 工种大地图 + 每类岗位一页 + 市场规律 | 岗位地图 | 第六章 | 第七章 P33–P38 |
| 尾声 | 学习之路（从广场出发的 N 条路）；塔顶俯瞰（一句话装下全行业）；封底 | 工具学习顺序、一句话记住全行业 | P43–P45 | P39–P41 |

每章开头写一段 2–3 句的章节导语，说明这一章在整座城里看什么。最后给出全书目录表：页 / 主题 / 城市里的比喻。

### 3. 定全局设定（每本书写一次）

照搬 `references/style-and-characters.md` 里的内容，只改两处：

- 风格段的色板：保留系列基础色 teal 和 coral，再换上一两种本行业专属色（比特城用芥末黄和石板蓝，金流城用暖金和深海军蓝）。
- 城市名、城市设定表。

角色定妆 prompt 和反向提示词原样保留，保证系列里人物一致。

### 4. 逐页写三段

每一页固定格式：

~~~markdown
### P<n> · <主题>：<城市里的比喻>

**配文**：印在绘本上的中文。用一个具体场景开头，Sylvan 看到或问到什么，比特用一句话点破本质，再补一两句现实里对应的机构或做法。必要时点出这个比喻的边界或风险。

**画面要点**：一句话，说这幅图必须让人一眼看懂的那件事。用来验收出图。

```text
<英文 prompt：场景 → 关键视觉比喻 → 小人们各自在做的具体工作 → Sylvan 与比特的位置和动作（每次都写全角色描述）→ 风格段原文>
```
~~~

写 prompt 的规则：

- **每段 prompt 独立可用**：角色描述每次写全，结尾附上完整风格段，不依赖上下文。
- **一页一个比喻**：画面只表达一件事，其余是氛围细节。
- **不画文字和数字**：报价屏、账本、图表一律用箭头、柱形、图标、颜色代替，避免模型画出乱码。
- **给配文留白**：内页顶部四分之一留空；封面顶部三分之一留给书名；封底下三分之一留给一句话。
- **画幅**：内页 4:3 横版，封面和封底 3:4 竖版。
- **不出现真实机构或品牌名**。

### 5. 写使用说明

手册开头放“使用说明”：这座城的核心比喻、全书页数、每页三部分是什么，以及出图步骤：

1. 先用定妆 prompt 生成 Sylvan 和比特（已有前作定妆图就直接复用）。
2. 逐页复制 prompt，每页都上传两张定妆参考图。
3. 文字后期排版加上。
4. 注意画幅与配色。
5. 不满意时只改 prompt 前半段的场景描述，不动结尾的 Style 段，全书画风就不会跑偏。
6. 说明绘本的比喻是为了抓本质，不是完整定义，建议配合速通手册一起读；涉及投资、医疗等领域时注明不构成建议。

## 自检清单

- [ ] 城市设定表里的每个地标都至少在一页出现过，每页用到的地标都在表里。
- [ ] 每页三段齐全，画面要点只有一句。
- [ ] 每段 prompt 都含完整角色描述和风格段，且写明 no text / no numbers。
- [ ] 第七章的岗位覆盖行业主要工种，尾声的学习之路能对应到前文地标。
- [ ] 塔顶俯瞰页的“一句话”能把全书的原理串起来。
