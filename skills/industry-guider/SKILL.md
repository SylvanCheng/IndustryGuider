# 行业速通：手册 + 绘本

目标读者是**完全的外行**：想在一天之内看懂一个行业是怎么运转的、要学什么、有哪些岗位、各岗位替谁解决什么问题。

对任意行业，按顺序产出两份东西：

1. **《X行业速通手册：课程体系 × 岗位 × 工具》**：一份可以一天读完的结构化手册。写法见 `references/handbook-guide.md`。
2. **《X城漫游记》绘本 Prompt 手册**：把同一套内容画成一座城市，每页有中文配文、画面要点和可直接复制的英文绘图 prompt。写法见 `references/picture-book-guide.md`，系列通用的画风与角色见 `references/style-and-characters.md`。

**先写手册，再写绘本。** 绘本的章节、比喻和岗位页都从手册里来，两份东西讲的是同一套结构，只是一个用表格讲，一个用城市讲。

## 输入

- **行业名称**（必填）。例如“医药”“半导体”“法律”“游戏”。
- 读者背景（可选）。默认是“聪明但完全不懂这一行的人”，用“老板的眼光”来讲：只关心每样东西在世界上解决什么问题，不讲公式和细节。
- 只要其中一份（可选）。用户只要手册或只要绘本时，只做那一份；只要绘本但没有手册时，先在心里把手册的骨架列出来再动笔。

## 工作流

### 第一步：找到行业的第一性原理和价值链

在写任何一个字之前，先回答三个问题，它们会贯穿两份产物：

1. **这个行业本质上只在做一件事，是什么？** 用一句话说出来。
   - 计算机：把“处理信息”的成本压到接近零。
   - 金融：把钱从“暂时用不上的人”转到“现在能用好的人”手里，并为过程里的风险定价。
2. **3–4 条第一性原理。** 每条都是后面所有课程和岗位的源头。
3. **一条价值链。** 用“A → B → C → D”写出行业里价值是怎么一层层产生和流动的，再补一句看不见的基础设施在哪里。每门课、每个岗位都要能卡在这条链上的某个位置。

### 第二步：写速通手册

按 `references/handbook-guide.md` 的固定结构写：导读、课程阶梯（L0–L4）、岗位地图、工具箱与大白话词典、总对照表，最后一句话记住全行业。

### 第三步：从手册推出城市

1. **核心比喻**：这个行业里流动的是什么？把它画成一种会发光、会流动、看得见的东西（计算机是城市分层结构里的信件、数据运河与电力；金融是“钱 = 金色的水”）。
2. **城市设定表**：把手册的价值链和课程层级映射成城市的“层”。一层 = 价值链的一段或一层课程，每层有固定的画面元素。
3. 给城市起名《X城漫游记》，延续系列主角 Sylvan 和向导机器人比特。

### 第四步：写绘本 Prompt 手册

按 `references/picture-book-guide.md` 写，章节一一对应手册：

| 手册 | 绘本 |
| --- | --- |
| 导读：一件事 + 第一性原理 + 价值链 | 序章：封面、这个行业在做什么、每条原理一页、城市全景剖面 |
| 课程阶梯 L0–L4 | 第一章起，每层课程一章，每门核心课一页 |
| 岗位地图 | “城里的人”一章：工种大地图 + 每类岗位一页 + 市场规律 |
| 工具学习顺序 | 尾声：学习之路（从广场出发的 N 条路） |
| 一句话记住全行业 | 尾声：塔顶俯瞰；最后是封底 |

### 第五步：交付

- 默认把两份产物写成文档（或 Markdown 文件），标题分别为《X行业速通手册：课程体系 × 岗位 × 工具》和《《X城漫游记》绘本 Prompt 手册》。
- 手册里的两张图（课程阶梯图、工具学习顺序图）用图示呈现；只能输出纯文本时用 Mermaid 流程图。
- 交付时告诉用户：先读手册，再按绘本手册的“出图步骤”出图。

## 质量要求

- **只讲“它在世界上解决什么问题”。** 每门课、每个工具、每个岗位都要能用一句大白话说清；术语一律放进词典。
- **每一节结尾都有“老板该记住的”**：一两句话的判断，而不是复述。
- **两份产物结构对得上**：手册里的每层课程、每类岗位，在绘本里都有对应的页；绘本里的每个地标，都能在手册里找到它代表的东西。
- **不构成建议**：涉及投资、医疗、法律等行业时，在导读和绘本使用说明里注明只讲行业结构。
