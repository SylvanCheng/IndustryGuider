# 金融行业速通手册：课程体系 × 岗位 × 工具

Nov 18, 2026 · @Sylvan

## 导读：用老板的眼光看金融行业

金融行业本质上只在做一件事：**把钱从“暂时用不上的人”那里，转到“现在能把它用好的人”手里，并为这个过程里的风险定价**。下面四条第一性原理，是后面所有课程和岗位的源头。

1. **时间有价格。** 今天的一块钱比明年的一块钱值钱，因为它今天就能拿去生钱。利息就是“时间的价格”。金融里几乎所有估值，都是把未来的钱折算回今天。
2. **风险可以被定价、拆分和转移。** 一家人承担不起房子失火，一万家人凑钱就能承担（保险）；把钱分散到很多地方，单个失败就不致命（分散投资）。风险越大，要求的回报就越高——这是整个行业的定价铁律。
3. **信用是杠杆。** 大家相信你会还，你就能用一块钱的本金办十块钱的事。杠杆让好时候赚得更多，也让坏时候亏得更狠。几乎每一次金融危机，核心都是信用和杠杆突然崩塌。
4. **价格就是信息。** 市场是一台把无数人的判断汇总成一个数字的机器。谁能更快、更准地处理信息，谁就能赚到钱；但信息一旦人人都知道，就已经在价格里了。

由此形成一条价值链：**资金提供者**（储户、养老金、保险公司）→ **中介**（银行、券商、基金）→ **资金使用者**（企业、政府、家庭）。在这条链的下面，还有一层看不见的**基础设施**：央行、支付清算、交易所和监管。每门课、每个岗位，都卡在这条链的某个位置上。

| 时段 | 读什么 | 读完应该能做到 |
| --- | --- | --- |
| 上午，约 2 小时 | 第一部分：课程阶梯图 + L0 到 L4 | 说出每门课在世界上解决什么问题、和哪门课相连 |
| 下午，约 3 小时 | 第二部分：岗位地图 + 工具学习顺序 + 词典 | 说出每个岗位替谁解决什么问题、靠什么吃饭 |
| 晚上，约 1 小时 | 总对照表，回看两张图 | 把任意一条财经新闻，定位到价值链的某一环 |

读法：每一项只抓“它在世界上解决什么问题”。专业名词不用记，需要时去词典里查。本手册讲的是行业结构，不构成任何投资建议。

## L0 数学与统计地基：给“不确定”算账

金融里的数学只为一件事服务：**给时间和风险算账**。微积分和线代用来描述“变化”和“组合”，概率统计用来描述“不确定”。量化和风控方向对数学要求很高，投行和财富管理则用得浅。

| 课程 | 一句话本质 | 它在金融世界里起什么作用 |
| --- | --- | --- |
| 微积分 | 研究“变化”和“累积” | 复利就是累积：利息生利息。债券价格对利率有多敏感、期权价格怎么随时间变化，都是微积分算出来的。 |
| 线性代数 | 把很多东西当成一个整体来算 | 一个投资组合里有几百只股票，它们之间的涨跌互相关联。线代把这张关系网一次性算清楚，是资产配置和风险模型的底层。 |
| 概率与统计 | 在不确定中做出有把握的判断 | 金融的核心商品就是风险。“这笔贷款有多大可能还不上”、“这个组合最坏会亏多少”，都是概率问题。保险和精算更是完全建立在它上面。 |
| 计量经济学 | 用数据检验经济规律是真是假 | “加息真的会压低通胀吗？”“这个选股策略是真有效还是运气？”计量经济学帮你分清因果和巧合，是研究员和量化的基本功。 |

老板该记住的：金融里的数学不是为了算得精确，而是为了知道“自己可能错多少”。数学越强的人，越靠近量化、风控和精算这些门槛高的岗位。

## L1 经济学与会计：所有方向的通用语言

如果说编程是计算机行业的通用语言，那么**会计和经济学就是金融行业的通用语言**。会计让你看懂一家公司，经济学让你看懂整个市场和国家。

| 课程 | 一句话本质 | 它在金融世界里起什么作用 |
| --- | --- | --- |
| 微观经济学 | 个人和企业怎么做选择：价格、供需、竞争、激励 | 判断一个行业赚不赚钱、能不能长期赚钱。一家公司有没有定价权、会不会被价格战拖垮，答案都在这里。 |
| 宏观经济学 | 整个国家的经济怎么运转：增长、通胀、利率、就业、周期 | 利率一变，所有资产的价格都跟着变。看懂央行为什么加息、经济为什么有繁荣和衰退，是任何投资判断的大背景。 |
| 会计学 | 商业世界的记账语言 | 资产负债表是公司此刻的家当，利润表是一年的成绩单，现金流量表是钱包里真实流进流出的钱。不懂这三张表，就看不懂任何一家公司，也识破不了财务造假。 |

老板该记住的：这一层是所有金融岗位的公共门槛。很多从其他行业转进金融的人，第一件事就是把会计三张表学透。它的投入产出比在金融里学任何其他东西都高。

## L2 金融核心：钱从哪里来、企业怎么用钱、投资者怎么选钱

这一层是金融专业的“三大主干课”，分别站在三个视角看同一笔钱：银行和央行怎么创造和调节它，企业怎么筹它和花它，投资者怎么选它的去处。

| 课程 | 一句话本质 | 它在金融世界里起什么作用 |
| --- | --- | --- |
| 货币银行学 | 钱是什么、银行怎么“变”出钱、央行怎么调节钱 | 银行把存款放贷出去，贷款又变成新的存款，钱就这样被放大。央行通过利率控制这台放大器的油门。看懂它，就看懂了放水、收紧、通胀和银行危机。 |
| 公司金融 | 一家企业该去哪里找钱、该把钱投到哪里 | 借钱还是卖股份？开新工厂还是收购对手？利润是分红还是再投入？这是 CFO 和投行每天在想的事，也是并购和上市的理论基础。 |
| 投资学 | 站在出钱的人这边：风险和回报怎么取舍 | 为什么不要把鸡蛋放在一个篮子里、为什么大多数主动基金跑不赢指数、一定的风险应该要求多少回报。这是基金、资管和财富管理的理论根基。 |
| 金融市场与机构 | 整个金融体系的地图：有哪些市场、哪些机构、谁和谁做生意 | 股票市场、债券市场、外汇市场、银行、券商、保险、基金、交易所各自是什么角色。相当于先看清城市地图，再去学每一栋楼。 |

老板该记住的：这三门课对应金融业的三大阵营——**银行与央行**（造钱和管钱的人）、**投行与企业**（用钱的人）、**基金与资管**（替人选钱去处的人）。

## L3 专业方向：把原理变成生意

从这里开始分流。每门课都直接对应一类岗位和一种赚钱方式。

| 课程 | 一句话本质 | 它在金融世界里起什么作用 |
| --- | --- | --- |
| 财务报表分析与企业估值 | 一家公司到底值多少钱 | 把公司未来能赚的钱折算成今天的价格，或者拿同类公司来比。上市定价、并购报价、买不买一只股票，都从这里开始。 |
| 并购与重组 | 公司之间的买卖和重新组合 | 投行收入最高的业务之一。核心问题是：买下来之后 1+1 能不能大于 2，或者拆开卖是不是比整体更值钱。 |
| 固定收益（债券） | 各种“借条”怎么定价、怎么交易 | 全球债券市场比股票市场还大。政府和企业借钱、银行和保险公司存放资金，都靠它。利率一动，债券价格立刻跟着动。 |
| 衍生品与金融工程 | 对未来价格的合约：期货、期权、互换 | 农民提前锁定秋天的粮价、航空公司锁定明年的油价，用的都是衍生品。它既能对冲风险，也能放大风险——工具本身不分善恶。 |
| 风险管理 | 把“可能亏多少”量化、设限、监控 | 信用风险（借钱不还）、市场风险（价格暴跌）、流动性风险（需要钱时变不出现）、操作风险（人和系统出错）。金融机构活下来靠的不是赚多少，而是不死。 |
| 国际金融 | 钱跨过国境时发生什么：汇率、资本流动 | 为什么一个国家加息会让另一个国家的货币贬值、跨国公司怎么应对汇率波动。外贸、跨国投资和外汇交易的基础。 |
| 保险与精算 | 用概率给“意外”定价 | 保险公司先收钱、后赔付，中间有一大笔长期资金。精算师决定保费收多少才不会亏，是门槛极高、非常稳定的职业。 |
| 金融监管与法律 | 金融游戏的规则和裁判 | 金融是被监管最严的行业之一，因为它用的是别人的钱，而且一家倒闭可能拖垮一串。牌照、资本要求、信息披露，都来自这里。 |
| 行为金融学 | 人为什么不理性，以及这对价格意味着什么 | 追涨杀跌、羊群效应、过度自信。它解释了泡沫和崩盘为什么反复出现，也解释了大多数个人投资者为什么亏钱。 |

老板该记住的：大致分三个大方向——走**公司线**（估值、并购）通向投行和 PE，走**市场线**（固收、衍生品、风控）通向交易和量化，走**制度线**（国际金融、监管、精算）通向央行、监管和保险。

## L4 前沿：金融遇上数据和算法

金融从一开始就是“信息业”：价格是信息，信用是信息，账本也是信息。所以它是被计算机和 AI 改造得最彻底的行业之一。这一层是三条主线和技术的汇合点。

| 课程 | 一句话本质 | 它在金融世界里起什么作用 |
| --- | --- | --- |
| 量化投资 | 用数学模型和程序代替人的直觉做买卖 | 从海量历史数据里找出可重复的规律，写成程序自动执行。在很多发达市场，相当一部分交易已经由程序完成。它是金融里对数学和编程要求最高的方向。 |
| 机器学习与 AI 金融应用 | 让机器从数据里学会判断风险和机会 | 信用评分、反欺诈、智能投顾、自动写研报和审合同。大模型正在压缩研究、合规和后台的重复劳动，让一个分析师能覆盖更多公司。 |
| 金融科技（FinTech） | 用软件重做银行、支付、贷款、保险 | 手机支付、纯线上银行、线上小额贷款。它的本质是把金融服务的成本压低，让过去服务不到的人也能用上。难点不在技术，而在牌照和风控。 |
| 区块链与数字资产 | 一本没有中心、人人共同记账的账本 | 尝试不靠银行等中介就完成转账和交易。支持者看重它的效率和开放性，批评者担心投机和监管缺口，各国监管态度差异很大，是仍在演变的领域。 |
| 可持续金融（ESG） | 把环境、社会、治理风险纳入投资判断 | 绿色债券、碳交易、气候风险评估。在欧洲尤其受重视，和能源转型紧密相连；在其他地区也有关于它是否过度包装的争论。 |

老板该记住的：金融和技术的交叉点是当前最稀缺的组合。懂金融的人很多，懂技术的人也很多，两边都懂、还能把技术放进强监管环境里的人很少。

## 第二部分 · 岗位地图：每个岗位替谁解决什么问题

金融机构赚钱只有几种方式：**帮人找钱收服务费**、**替人管钱收管理费**、**用自己或客户的钱做交易赚差价**、**借入和借出的利差**。行内常把岗位分为前台（直接赚钱）、中台（管住风险）、后台（让一切跑起来）。看懂一个岗位，还是两个问题：它替谁解决什么问题？没有它会怎样？

### 一、帮企业找钱（卖方 · 前台）

| 岗位 | 替谁解决什么问题 | 没有它会怎样 | 关键技能与工具 |
| --- | --- | --- | --- |
| 投资银行（IPO、并购、发债） | 帮企业上市、发债、买卖公司，设计交易结构并找到买家 | 企业和投资者之间没有桥，大交易做不成 | 会计、估值、Excel 建模、路演材料、谈判、极长工时 |
| 企业银行 / 公司信贷 | 给企业放贷款、做结算和现金管理 | 企业日常周转和扩张缺钱 | 信贷分析、财报、行业知识、客户关系 |
| 研究员（卖方） | 写行业和公司研报，给机构投资者参考 | 投资者要自己从头研究每家公司 | 行业研究、估值、写作、路演表达 |

### 二、替别人管钱（买方）

| 岗位 | 替谁解决什么问题 | 没有它会怎样 | 关键技能与工具 |
| --- | --- | --- | --- |
| 基金经理 / 投资经理 | 决定一大笔钱买什么、卖什么、买多少 | 养老金、保险金和普通人的积蓄无人专业打理 | 投资学、估值、宏观判断、风险控制、心理素质 |
| 买方研究员 | 给基金经理找标的、判断值不值得买 | 基金经理看不过来那么多公司 | 行业研究、财务分析、实地调研 |
| 私募股权（PE） | 买下整家公司或大块股权，改造后高价卖出 | 经营不善但有潜力的公司没人出钱改造 | 估值、尽职调查、交易结构、经营改善 |
| 风险投资（VC） | 给早期创业公司投钱，赌少数公司成长为巨头 | 有想法但没钱的创业者起不来 | 判断人和市场、行业趋势、人脉 |
| 财富管理 / 私人银行 | 替富裕家庭做资产配置、税务和传承规划 | 家庭财富没人系统地保值和传承 | 产品知识、资产配置、信任与关系管理 |

### 三、在市场里交易

| 岗位 | 替谁解决什么问题 | 没有它会怎样 | 关键技能与工具 |
| --- | --- | --- | --- |
| 交易员 / 做市商 | 随时报出买价和卖价，让市场随时能成交 | 想买的人找不到卖家，市场不流动 | 市场直觉、衍生品、风险控制、抗压 |
| 量化研究员 | 用数学和数据找可重复的赚钱规律 | 交易只靠直觉，无法规模化 | 概率统计、Python、机器学习、回测 |
| 量化开发 / 交易系统工程师 | 把策略变成又快又稳的交易系统 | 策略再好也执行不了或慢人一步 | C++ / Python、低延迟系统、网络 |

### 四、管住风险与规则（中台）

| 岗位 | 替谁解决什么问题 | 没有它会怎样 | 关键技能与工具 |
| --- | --- | --- | --- |
| 风险管理 | 量化机构可能亏多少、设上限、做压力测试 | 一笔大亏损就能让机构倒闭 | 概率统计、风险模型、监管规则 |
| 合规 / 反洗钱 | 确保业务合法，拦住洗钱和欺诈 | 巨额罚款、牌照被吊销 | 法规知识、数据分析、细致 |
| 审计 | 独立检查公司的账是不是真的 | 投资者无法相信任何财报 | 会计、审计准则、职业怀疑 |
| 精算师 | 给保险和养老金的未来赔付定价和备钱 | 保险公司收少了会赔穿，收多了卖不动 | 概率统计、精算模型、长期考证 |

### 五、企业里的金融与基础设施

| 岗位 | 替谁解决什么问题 | 没有它会怎样 | 关键技能与工具 |
| --- | --- | --- | --- |
| CFO / 财务分析（FP&A） | 替公司做预算、管现金、筹钱、给老板决策依据 | 公司不知道钱花在哪、还能撑多久 | 会计、公司金融、建模、业务理解 |
| 央行 / 金融监管 | 调节利率和货币、维护金融系统稳定 | 通胀失控、银行连环倒闭 | 宏观经济、计量、政策与法律 |
| 支付清算 / 交易所 | 让每一笔钱准确、及时地从 A 到 B | 买卖无法交割、钱到不了账 | 系统工程、规则设计、风控 |
| 金融科技产品 / 工程师 | 用软件重做支付、贷款、理财、风控 | 金融服务慢、贵、覆盖面窄 | 后端开发、数据、风控模型、合规意识 |

### 市场规律：哪些岗位更值钱、更稳

- **前台离钱最近，收入弹性也最大。** 投行、交易、基金经理的收入和业绩、行情挂钩，好年份很高，坏年份裁员也最先开始。中后台收入低一些，但更稳。
- **金融高度依赖牌照和证书。** CFA（投资）、FRM（风控）、CPA（会计审计）、精算师资格、各地的从业资格考试，都是入场券或加分项。具体哪个证书有用，因国家和岗位而异。
- **校招和出身比很多行业更重要。** 顶级投行和基金的入口很窄，很多人是从实习一路转正的。中途转行更容易从中后台、企业财务或金融科技切入。
- **行业强周期。** 牛市里投行和基金招人抢人，熊市里整个部门可能被裁。入行时机会影响起点。
- **技术正在重写中后台和研究。** 重复性的数据整理、初级研报、合规审核最容易被 AI 压缩；懂金融又懂技术的交叉人才最缺。

读法：左边六项是任何金融岗位的入场券；分支之间可以流动，比如从投行转去 PE、从研究转去基金经理都是常见路径；有技术背景的人最容易从量化和金融科技切入。

### 通用基础（所有岗位）

| 工具 / 概念 | 大白话：是什么 | 在行业里干什么用 |
| --- | --- | --- |
| 三张财务报表 | 资产负债表（家当）、利润表（成绩单）、现金流量表（真实的钱包） | 看懂任何一家公司的第一步 |
| 货币时间价值 / 折现 | 把未来的钱换算成今天值多少 | 所有估值、贷款、债券定价的数学核心 |
| Excel 财务建模 | 用电子表格把一家公司的未来推演出来 | 投行、PE、研究、企业财务的日常工具 |
| 数据终端（彭博、Wind、FactSet 等） | 汇集行情、新闻、财报的专业数据平台 | 交易员和研究员的“眼睛” |
| Python / SQL | 处理大量数据的编程工具 | 量化、风控、数据分析的必备，其他岗位也越来越需要 |
| 写作与汇报 | 把复杂判断说清楚、说服人 | 研报、投资备忘录、路演、客户沟通 |

### 估值与投资

| 工具 / 概念 | 大白话：是什么 | 在行业里干什么用 |
| --- | --- | --- |
| DCF（现金流折现） | 把公司未来每年能赚的现金折回今天加起来 | 估算公司“内在价值”的经典方法 |
| 可比公司法（市盈率、市净率等） | 看同类公司卖多少钱，按比例推算 | 最常用、最快的估值方法 |
| 资产配置 | 决定钱分多少在股票、债券、现金、其他资产 | 对长期回报影响最大的一个决定 |
| 指数基金 / ETF | 一次买下一篮子股票、跟着大盘走的基金 | 低成本分散投资，正在大量替代主动基金 |
| 尽职调查 | 买之前把公司里里外外查一遍 | PE、并购、上市前的必经步骤 |

### 市场与交易

| 工具 / 概念 | 大白话：是什么 | 在行业里干什么用 |
| --- | --- | --- |
| 股票 | 一家公司的一小块所有权 | 分享公司成长，也承担公司失败 |
| 债券 | 一张标准化的借条，到期还本付息 | 政府和企业借钱的主要方式 |
| 久期 | 债券价格对利率变化有多敏感 | 利率一变、债券组合会亏多少的尺子 |
| 期货 | 约定未来按固定价格买卖 | 锁定原材料、汇率等价格风险 |
| 期权 | 花一笔小钱买到“未来可以买（或卖）、也可以不买”的权利 | 像给资产买保险，也可以用来放大押注 |
| 对冲 | 用一笔交易抵消另一笔的风险 | 企业和机构控制风险的基本动作 |
| 杠杆 | 借钱来放大投资规模 | 赚钱时放大收益，亏钱时放大损失 |
| 回测 | 用历史数据模拟一个策略过去会怎样 | 量化策略上线前的必经步骤 |

### 风险、合规与证书

| 工具 / 概念 | 大白话：是什么 | 在行业里干什么用 |
| --- | --- | --- |
| VaR（风险价值） | “在正常市况下，最坏大概会亏多少” | 金融机构量化风险的常用指标 |
| 压力测试 | 假设发生极端情况，看机构会不会倒 | 监管和风控的重要工具 |
| 巴塞尔协议 | 国际通行的银行监管标准 | 规定银行至少要有多少自有资本来扛损失 |
| KYC / 反洗钱 | “了解你的客户”：核实身份和资金来源 | 阻止非法资金进入金融系统 |
| CFA | 投资领域最通用的国际资格证书 | 资管、研究、财富管理的入场券 |
| FRM | 风险管理方向的国际证书 | 风控岗位的加分项 |
| CPA / ACCA | 会计和审计方向的资格证书 | 审计、企业财务、投行的础石 |

### 金融科技

| 工具 / 概念 | 大白话：是什么 | 在行业里干什么用 |
| --- | --- | --- |
| 支付清算系统 | 钱从 A 账户到 B 账户背后的管道和规则 | 每一笔刷卡、转账、跨境汇款的底座 |
| 信用评分模型 | 用数据预测一个人或企业会不会还钱 | 贷款审批和定价的核心 |
| 开放银行 / API | 银行把服务开放给第三方应用调用 | 让金融服务嵌入各种 App，欧洲推得较早 |
| 区块链 | 一本多方共同维护、难以篡改的账本 | 数字资产、跨境结算等领域的尝试 |
| 监管科技（RegTech） | 用技术自动完成合规检查和报告 | 降低合规成本，是 AI 落地最快的场景之一 |

## 总对照：岗位 × 价值链 × 课程 × 护城河

把两部分串起来：每个方向在价值链哪一段、靠哪几层课程打底、长期竞争力来自哪里。

| 方向 | 价值链位置 | 最依赖的课程 | 护城河来自哪里 |
| --- | --- | --- | --- |
| 投行 / 公司金融 | 中介：连接企业和资金 | L1 会计 + L2 公司金融 + L3 估值、并购 | 交易经验和客户关系 |
| 资产管理 / 投资研究 | 中介：替资金提供者做选择 | L1 + L2 投资学 + L3 估值 | 可验证的长期业绩和判断力 |
| PE / VC | 资金直接进入企业 | L2 公司金融 + L3 估值、并购 | 行业眼光、人脉、交易流 |
| 交易 / 量化 | 市场层：让价格成形 | L0 概率统计 + L3 衍生品 + L4 量化 | 数学和编程的深度、系统速度 |
| 风控 / 合规 / 审计 | 基础设施：守住底线 | L0 统计 + L3 风险管理、监管 | 证书、规则熟练度、经历过的危机 |
| 保险 / 精算 | 资金提供者：汇集长期资金 | L0 概率统计 + L3 精算 | 极高的考证门槛 |
| 银行 / 财富管理 | 中介：吸储、放贷、配置 | L2 货币银行 + 投资学 | 客户信任与关系 |
| 央行 / 监管 | 基础设施：制定规则 | L1 宏观 + L2 货币银行 + L3 国际金融、监管 | 政策研究深度 |
| 金融科技 | 基础设施 × 中介：用软件重做服务 | L2 + L4 + 计算机技术 | 金融、技术、合规三者兼备 |

一句话记住全行业：**会计是语言，利率是时间的价格，风险是唯一的商品，信用是杠杆，市场是处理信息的机器。** 岗位，就是这条资金流动链上不同的关卡。
